# Aarti Giri — Premium Portfolio Website

A luxury personal branding portfolio for **Aarti Giri**, Executive Assistant & HR Professional.

---

## 📁 File Structure

```
aarti-portfolio/
├── index.html       ← Main portfolio page (all sections)
├── style.css        ← Premium design system
├── script.js        ← Animations, particles, interactions
├── profile.jpg      ← Your professional photo (ADD THIS)
└── resume.pdf       ← Your resume file (ADD THIS)
```

---

## 🚀 Quick Setup

1. **Add your photo**: Place `profile.jpg` in this folder.
2. **Add your resume**: Place `resume.pdf` in this folder.
3. **Update contact details** in `index.html`:
   - Email: search for `aarti.giri@email.com` and replace
   - LinkedIn URL: search for `linkedin.com/in/aarti-giri` and replace
4. Open `index.html` in any browser — it works offline too!

## 🌐 Deployment

### GitHub Pages (Free)
1. Create a GitHub repository (e.g., `aarti-giri-portfolio`)
2. Upload all files to the repo
3. Go to **Settings → Pages → Source → Main branch**
4. Your site will be live at `https://yourusername.github.io/aarti-giri-portfolio`

### Netlify (Free, Easiest)
1. Go to [netlify.com](https://netlify.com) → Sign up free
2. Drag and drop this entire folder onto the Netlify dashboard
3. Site goes live instantly with a URL like `https://aarti-giri.netlify.app`

### Custom Domain
Add your domain in Netlify/GitHub Pages settings and update DNS records.

## ✏️ Customization

| What to change | Where |
|----------------|-------|
| Name, title, bio | `index.html` → Hero section |
| Contact details | `index.html` → Contact section |
| Work experience | `index.html` → Experience section |
| Colors | `style.css` → `:root` CSS variables |
| Typed phrases | `script.js` → `phrases` array |
| Profile photo | Replace `profile.jpg` |
